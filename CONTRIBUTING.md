# Contributing

Useful contributions make deterministic pixel assets easier for AI agents and people to create, edit and verify. Small reproducible fixes, clearer workflows and original examples are welcome.

## Report a problem

[Open an issue](https://github.com/Chenamel/deterministic-pixel-art/issues) with the package version or commit, operating system, Python/Pillow versions, exact command, expected result and actual error. Attach a minimal spec or PNG when useful. Remove credentials and private project data. For an installation problem, include the chosen installation method and whether command execution or Skill discovery failed.

## Propose a change

Explain the user task and a reproducible obstacle before adding a new command or dependency. Keep JSON v1, public APIs and default pixels compatible; put intended visual changes in separate candidates. Original artwork and externally sourced material need clear licensing and provenance.

Edit `src/` for runtime code, `recipes/` for short generators and `skill-content/` for Skill guidance. The `skill/` directory is generated by `tools/package_skill.py`; avoid editing generated copies directly.

Run the checks from a checkout with Python and the development requirements:

```sh
python -m pip install -r requirements-dev.txt
python -B tools/check.py
```

For documentation changes, check relative links, matching English/Chinese sections and the commands you changed. Rebuild the README gallery with `python tools/build_readme_gallery.py`; it reuses existing original assets and rearranges UI cells for display without repainting them. Full checks generate local artifacts without installing globally. Describe what you tested and what remains unverified in the pull request. [README](README.md) · [中文首页](README.zh-CN.md).
