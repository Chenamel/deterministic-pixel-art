# 制作六状态按钮与文字预览

使用包内 Skill 和按钮配方完成任务，结果保存到 `RUN/`。

## 开始

1. 解压后进入本任务目录，读取 `deterministic-pixel-art/SKILL.md`，再按需查看配方和文字集成说明。
2. 使用 Python 3.10+；需要依赖时，在任务局部虚拟环境安装 `deterministic-pixel-art/requirements.txt`。
3. 用同一个解释器启动记录：

```text
python run.py start --platform "WorkBuddy" --model "当前模型名"
```

工具通过 `python run.py tool <参数>` 调用；配方或辅助脚本通过 `python run.py script <任务目录内的.py路径> <参数>` 调用。这些命令会自动留下记录。

## 需求

制作六状态按钮，名称和顺序为 `normal, hover, focus, pressed, selected, disabled`，继承配方的图标、浮雕和蓝色基调。文字另在消费端绘制，源贴图不含文字。

- 每枚按钮高18px，统一偶数宽度、不超过112px。根据实际字体边界和内边距选择紧凑宽度。
- 标签为 `START`、`LOOP`、`EXPORT MAP`，使用 `inputs/Silkscreen-Regular.ttf`，字号8px。
- 每个状态有一个文字预留矩形。按局部 `x,y,w,h` 表示：`x>=23`、`y>=4`、`x+w<=按钮宽度-2`、`y+h<=14`；实际文字边界在矩形四边各留至少2px。
- 布局、PNG 和 Context 从同一次构建生成。Context 中的全局文字区域名为 `<状态名>-text`，role 为 `reserved_text`。
- 另外合成18个实例：3列依次为三个标签，6行依次为六状态；不加标题或间隔。保存原尺寸 `RUN/consumer.png` 和最近邻3倍图 `RUN/consumer-3x.png`。

先在 `RUN/initial-notes.md` 用一句话记录准备采用的入口。完成后查看原尺寸与放大图，检查文字、图标、边框及状态区别。

## 提交

- `RUN/final.json`、`final.png`、`final-layout.json`、`context.json`。
- 两张消费端图、相关辅助源码及三个标签的实际字体边界。
- `RUN/text-fit.json`：`font_size:8`；`instances` 含18项，每项记录 `state`、`label`、`origin:[x,y]`。origin 是 `ImageDraw.text` 在消费端的全局原点。可选 `color` 为6/8位十六进制，省略时禁用态用 `8997A5`，其余用 `E5ECEE`。
- 简短的 `RUN/feedback.md`：实际卡在哪里、如何解决、还有哪个步骤需要改进；注明相关命令或文件。

最多两个候选、两轮修正，候选使用新目录。保留失败；无法继续时说明原因。输入、Skill 和记录器保持原样。

```text
python run.py check
python run.py finish --status complete
```

无法继续或额度不足时，最后一条分别用 `--status blocked` 或 `--status quota_limited`。交回 `submission-LT02.zip`；平台可直接导出会话时，一并提供。
