# Linux环境与PNG无损往返

读取 `deterministic-pixel-art/SKILL.md`，实际运行包内工具。不要修改输入、Skill或记录器，不安装到全局环境。

## 开始

使用Python3.10+、Pillow>=10.4,<13；复现基准为12.3.0。缺少依赖时，在任务局部虚拟环境安装 `deterministic-pixel-art/requirements.txt`。若解压盘不支持创建环境，可在本地临时目录建环境；之后始终用该环境的Python调用run.py，不要将解释器符号链接解析到系统Python。

```text
python run.py start --platform "当前平台" --model "平台显示的模型名称"
```

下文 `python` 均指同一解释器。工具通过 `python run.py tool <参数>` 调用；自写的辅助脚本放任务目录内，用 `python run.py script <相对路径> <参数>` 调用并保留。

## 完成三项

1. **PNG往返。** 将 `inputs/rgba.png`、`inputs/rgb.png`、`inputs/indexed.png` 分别导入可编辑规格，再渲染回PNG。保存到 `RUN/roundtrip/<原文件名去扩展名>.json` 和同名 `.png`。比较原图与结果的尺寸和解码后RGBA逐像素值，包括半透明及透明像素里的RGB。不要量化颜色。
2. **默认与便携输出。** 先用默认输出方式渲染 `inputs/panel.json` 到 `RUN/native/panel.png`，另输出 `RUN/native/preview.png`；保留原目录失败。然后显式使用 `--portable-output`，渲染同一规格到 `RUN/portable/panel.png` 和 `RUN/portable/preview.png`，预览背景为 `E9EDF2`。再次向已有的便携PNG渲染，不用 `--force`，确认拒绝覆盖且原文件哈希不变；该次返回2是预期结果，继续任务。再为便携PNG输出审阅目录 `RUN/review/`，使用 `inputs/panel-context.json`。
3. **环境与观察。** 实际查看便携预览和审阅图，在 `RUN/feedback.md` 简短记录有具体命令或图片依据的困难、恢复方法和最需要改进的一点。`RUN/environment-notes.md` 记录Python/Pillow路径与版本、解压/输出位置、默认与便携结果；不知道挂载类型就写未知。

若默认输出失败，保留失败命令，继续便携输出。若输入盘无法写入整个任务，可在临时目录解压新副本继续，并保留原位置/错误说明；不要以 `--force` 绕过挂载问题。需要时往返和审阅也可显式使用 `--portable-output`。不要捏造某种挂载错误，也不用探索或修改系统配置。
