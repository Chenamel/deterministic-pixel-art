# 原生小图标与局部修改

读取 `deterministic-pixel-art/SKILL.md`，用包内工具完成下面的像素资产。输入、Skill和记录器保持原样；自写源码及所有产物放在 `RUN/`，不安装到全局。

## 开始

使用Python3.10+、Pillow>=10.4,<13，精确复现基准12.3.0。需要时在局部环境安装 `deterministic-pixel-art/requirements.txt`；环境创建失败时，读取Skill的 `references/workflows.md` 环境恢复一节。

```text
python run.py start --platform "当前平台" --model "平台显示的模型名"
```

始终使用同一Python。工具通过 `python run.py tool <参数>` 调用；配方或自写脚本通过 `python run.py script <任务目录内的.py路径> <参数>` 调用，失败也会记录。挂载拒绝硬链接时，可用Skill所述的显式便携输出方式。

## 绘制

为小型探索游戏制作一套无文字工具栏图标，约束也见 `inputs/brief.json`：

| 图集 | 单格 | 从左到右的名称与含义 | 文件 |
|---|---|---|---|
| directions | 12×12 | up上、down下、left左、right右 | `RUN/v1/directions.json`、`.png`、`-layout.json` |
| actions | 16×16 | bag背包、map地图、settings设置、close关闭 | `RUN/v1/actions.json`、`.png`、`-layout.json` |

每个图集一行四格，使用命名单元；原生尺寸绘制，不从小图放大。两套共用最多8种可见颜色，透明不计；仅使用完全透明或不透明像素，每格保留1px透明边框。自行选择一致的描边、配色和光源规则；方向和功能应靠形状辨认，不只靠换色。

可先在候选目录试画，选定后再写入v1并实际查看。然后单独执行一次修改：**在map图标中加入清晰的小定位标记**，保留地图含义。输出 `RUN/v2/actions.json`、`actions.png`、`actions-layout.json`，其余三个功能图标的全部RGBA及布局不变。进入v2后保留v1，不覆盖；用工具验证修改只在map单元内，报告保存为 `RUN/change.json`。

为最终directions和actions图集分别输出 `RUN/views/<图集名>-<dark或light>-<1或8>x.png`：背景dark为 `182637`、light为 `E9EDF2`，各含原尺寸及最近邻8倍图。可以使用工具或通过记录器运行辅助脚本批量生成。实际查看两种背景，检查方向、四种功能、定位标记和整套视觉重量。最多两轮针对性修正，用新目录保留中间版本，选定后再写尚未占用的交付路径。

```text
python run.py check
python run.py finish --status complete
```

交回 `submission-LT04.zip`。无法继续或额度不足时将最后状态改为 `blocked` 或 `quota_limited`，保留失败和已有产物。平台方便导出时可附会话；不能导出无需重建完整对话。
