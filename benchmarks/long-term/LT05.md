# 小飞船与信号灯改色

读取 `deterministic-pixel-art/SKILL.md`，使用包内工具完成任务。输入、Skill和记录器保持原样；产物与自写源码放在 `RUN/`，无需全局安装。

## 开始

使用Python3.10+、Pillow>=10.4,<13；精确复现基准12.3.0。需要时按Skill说明安装依赖，虚拟环境放在 `RUN/` 外；环境恢复步骤见 `references/workflows.md`。

```text
python run.py start --platform "当前平台" --model "平台显示的模型名"
```

后续始终使用同一Python。工具经 `python run.py tool <参数>` 调用；自写脚本经 `python run.py script <任务目录内的.py路径> <参数>` 调用，失败也保留。输出方式按当前文件系统选择Skill中说明的默认或显式便携方式。

## 先画v1，再修改v2

为小型探索游戏新画一张 **32×32、透明背景的侧视小飞船**：船头向右、尾部向左，有可辨认的驾驶舱和发动机，整体非对称。自行决定造型、配色、光源与表现方式；不直接交付包内示例图，不把小图放大代替原生绘制。

飞船顶部有一盏信号灯，位于 `[12,2,8,6]`（x、y、宽、高，右/下端不包含）。灯的基色为不透明 `F5C26B`；外壳、高光可用其他颜色，主体应在该矩形之外。尺寸和颜色要求也见 `inputs/brief.json`。

1. 完成 `RUN/v1/sprite.json` 和 `sprite.png`：JSON应能用包内渲染器独立重建PNG。可用网格、绘制指令或Python生成规格。实际查看v1并选定后，保留它。
2. 再做一次小改：只将该矩形内的灯基色 `F5C26B` 改为 `62D8E8`，保留高光、外壳和其余全部RGBA。输出 `RUN/v2/sprite.json`、`sprite.png`。用工具验证修改范围，报告保存到 `RUN/change.json`。
3. 为v2输出 `RUN/views/<dark或light>-<1或8>x.png`：dark背景 `182637`、light背景 `E9EDF2`，原尺寸和最近邻8倍共4张。实际查看v1/v2和预览，核对头尾、灯与主体关系及改色范围。

保留用过的自写源码。若生成脚本会修改，把v1对应源码放在 `RUN/v1/`，v2另存副本；共用且未变的源码保留一份即可。探索稿放新目录，最多两轮针对性修正，不删除已查看版本或占用交付路径反复重建；进入v2后保持v1不变。无需为简单改色额外制作候选。
