# 同一个储物箱的三种材质

读取`deterministic-pixel-art/SKILL.md`，用包内工具完成任务。输入、Skill和记录器保持原样；产物与自写源码放在`RUN/`，无需全局安装。

## 开始

使用Python3.10+、Pillow>=10.4,<13；精确复现基准12.3.0。需要时按Skill安装依赖，虚拟环境放在`RUN/`外；环境恢复见`references/workflows.md`。

```text
python run.py start --platform "当前平台" --model "平台显示的模型名"
```

后续始终使用同一Python。工具经`python run.py tool <参数>`调用；自写脚本经`python run.py script <任务目录内的.py路径> <参数>`调用，失败也保留。输出方式按当前文件系统选择Skill说明的默认或显式便携方式。

## 绘制与交付

为小型探索游戏新画一个**32×32透明背景的带盖储物箱**，正面略见顶面，包含箱盖分界及锁扣或把手。用同一造型做**木材、金属、石材**三版：外轮廓、逐像素Alpha、朝向和主要结构位置相同；通过适合材质的纹理、明暗或反光表达区别，不仅统一换色。自行决定风格、配色与绘制方式，不直接交付Skill示例。

1. 三版排成一行命名图集，单元依次为`wood`、`metal`、`stone`，各32×32。交付可独立重渲染的`RUN/materials.json`、`RUN/materials.png`（96×32）及工具生成的`RUN/layout.json`。复用造型的实现方式自行选择；保留用过的自写源码。
2. 用工具输出`RUN/views/<dark或light>-<1或8>x.png`：dark背景`182637`、light背景`E9EDF2`，原尺寸和最近邻8倍共4张。PNG、布局和预览通过包内工具生成并记录。
3. 实际打开原尺寸和放大图，检查三版仍是同一物体、材质是否可辨、深浅背景是否可读。需要修正时最多两轮，已查看的探索稿和对应源码分目录保留；最终选定后保留交付文件。无需为凑轮次反复修改。

尺寸、名称和背景也见`inputs/brief.json`。`RUN/feedback.md`简短写实际困难、采用的造型复用方式、用过的说明，以及最希望改进的一点；没有困难就如实写没有。指出具体命令或文件位置，不用综合评分。

```text
python run.py check
python run.py finish --status complete
```

返回`submission-LT06.zip`。无法继续或额度不足时，用`blocked`或`quota_limited`结束并保留现有产物。平台方便时可附原始会话，不能导出无需重建。
