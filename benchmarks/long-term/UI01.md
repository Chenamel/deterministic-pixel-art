# 制作带真实文字预览的六状态按钮

1. 读取 `deterministic-pixel-art/SKILL.md`，按需查看配方和文字集成说明。使用 Python3.10+；缺少依赖时在任务局部环境安装 Skill 的 `requirements.txt`。
2. 用同一个解释器启动记录：

```text
python run.py start --platform "当前平台" --model "当前模型名"
```

配方或辅助脚本用 `python run.py script <任务目录内的.py路径> <参数>` 调用；核心工具用 `python run.py tool <参数>`。优先使用 Skill 已有入口；自写的辅助文件一并保留。

## 需要的结果

- 继承按钮配方的图标、浮雕、蓝色基调和六个状态，顺序为 `normal, hover, focus, pressed, selected, disabled`。源贴图不含文字。
- 每枚按钮高18px，统一偶数宽度、不超过112px；根据实际字体和边距选择紧凑宽度。
- 文字为 `START`、`LOOP`、`EXPORT MAP`，使用 `inputs/Silkscreen-Regular.ttf`、8px字号、单色字体覆盖。普通文字色 `E5ECEE`，禁用态 `8997A5`。
- 每个状态声明一个 `<状态名>-text` 的 `reserved_text` 区域。局部矩形 `[x,y,w,h]` 满足 `x>=23, y>=4, x+w<=宽度-2, y+h<=14`；实际文字四边各留至少2px。
- 同一标签在各状态保持相同局部位置，按下态文字随图标向下移动1px。布局和文字预留区随PNG一起生成。
- 合成18个实例：三列是三个标签，六行是六状态，无标题和间隔；另输出最近邻3倍图。

## 保存与交回

- `RUN/buttons/`：`asset.json`、`asset.png`、`layout.json`、`context.json`。
- `RUN/consumer/`：`consumer.png`、`consumer-3x.png`、`text-fit.json`，记录实际字体、字体边界及18个绘制原点。可直接采用 Skill 辅助入口的输出格式。
- 查看原尺寸和放大图。在 `RUN/feedback.md` 简短写实际遇到的障碍、如何解决及最需要改进的一点；没有障碍可直接说明。

最多两个候选、两轮修正，候选使用新目录；最终文件放在上述位置。保留失败，输入、Skill和记录器保持原样。

```text
python run.py check
python run.py finish --status complete
```

无法继续或额度不足时，最后一条分别改用 `--status blocked` 或 `--status quota_limited`。交回 `submission-UI01.zip`；平台能直接导出会话时一并提供。
