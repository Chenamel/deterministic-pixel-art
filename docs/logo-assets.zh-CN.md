# Logo 素材与后续发行

## 默认使用哪一版

| 外观 | 32 / 64 / 128 | 256 / 512 |
|---|---|---|
| 深底、浅底徽章 | 简洁版 | 增强版 |
| 深色背景、浅色背景用透明图形 | 简洁平面版 | 简洁平面版 |
| 透明底纯黑、纯白图形 | 单色版 | 单色版 |

每种外观和尺寸只有一份推荐文件，不再让使用者在大尺寸基础版与增强版之间选择。
总共六种外观、五种常用尺寸，即 30 张 PNG，每张都附独立可编辑 JSON。
这里的“全尺寸”指这五种常用尺寸，不是每个整数尺寸都输出一遍。

素材入口：[中文说明](../assets/brand/logo-kit/README.zh-CN.md)、[English](../assets/brand/logo-kit/README.md)。
32/128 深底 PNG 与正式 v1.2.1 的图标相同；本批不修改已发布 Skill 和本地安装。

## 怎样使用

- 界面的小图标直接选 32/64/128，不要把增强版缩得很小。
- 较大的徽章、头像和展示图选 256/512，已默认使用增强版。
- 自己提供背景时使用透明图形，按深浅背景选择配色；纯黑/纯白适合只使用一种颜色的场合。
- PNG 不会自动切换主题，素材说明中提供了网页按系统深浅主题选择图片的示例。

旧版全部基础尺寸、分开的增强稿和首轮 ZIP 留在原工作区与本地证据中。
本目录是当前选定的发行素材，不把历史候选一并交给下载者。

## 后续 Release 怎样带上完整素材

完整素材作为独立附件 `deterministic-pixel-art-logos.zip`，不把所有尺寸塞进 Skill ZIP。
Skill 继续只带其展示配置使用的 32/128 图标。

```sh
python tools/package_logo_assets.py --out dist/logo-assets-next
```

打包前会核对 30 个推荐资产、对应规格及全部文件摘要；已有输出目录会被拒绝，避免覆盖旧包。
生成的 ZIP 包含 67 个文件，另附一行 ZIP 校验值。
下次发布时，把 Logo ZIP 与正式 Skill ZIP 一起上传，并将两者纳入同一份 Release 校验清单。
中英文版本说明直接在页面阅读；不要为了附加 Logo 重发旧版本或替换旧下载。
完整顺序见[发布清单](releases/README.md)。

若今后确需修改图形，用[生成脚本](../assets/brand/build_logo_kit.py)重建到新目录并审阅：

```sh
python assets/brand/build_logo_kit.py --skill skill/deterministic-pixel-art --out output/logo-rebuild
```

本轮只整理选择和交付方式，不新增绘图能力、修改版本号或立即发布。
原生 512 绘画阶段仍暂缓；这套 Logo 的 512 图来自已选图形及轻细节版的整数放大。
