# P2：用可读配方完成常见修改

2026-10-23 · **v1.2.0-rc.3本地候选** · [English](recipe-workflows.md)

增加四份随Skill分发的Python配方：图标组、六态按钮、原生128飞船、256组件场景。它们复用现有渲染/写入接口，不增加JSON版本、运行依赖、缓存或新绘图命令。原仓库范例生成器也复用同一份几何源码，避免两套实现漂移。

```text
python <skill>/scripts/recipes/icons.py --out-dir icons --ink F5C26B
python <skill>/scripts/recipes/buttons.py --out-dir buttons --width 64 --content 28 4 30 10 --hover 426B83
python <skill>/scripts/recipes/courier128.py --out-dir courier --stripe E17B57 --stripe-light F9D5A0
python <skill>/scripts/recipes/scene256.py --out-dir scene --roof 684C6A --roof-light A07A89
```

每份输出可独立重渲染的 `asset.json`、`asset.png`、新布局和预览。按钮额外输出跟随尺寸和单元位置计算的文字预留区；场景重渲染全部小组件，再输出拼合清单、结果和接缝图。已有产物成组拒绝覆盖，显式 `--force` 才重建，支持 `--portable-output`。详细选项见 [Skill配方指南](../skill/deterministic-pixel-art/references/recipes.md)。

## 实际验证与收益

只使用候选ZIP，在中文空格路径、无仓库PYTHONPATH的独立工作目录完成17次命令调用，包含一次预期拒绝覆盖，意外失败0。四份无参数配方在Pillow12.3.0下与冻结rc.2参考图RGBA完全一致。

| 固定小改 | 实际结果 |
|---|---|
| 图标强调色 | 只改一个命名色；图标剪影、透明度、名称和布局不变 |
| 按钮宽度、文字区、一个状态 | 宽度32→64，六态顺序不变；文字区自动换算为图集绝对坐标；同宽对照只改hover的832像素，单元外变化0 |
| 128飞船指定部位 | 两个装饰带颜色参数，328像素变化全部在 `[42,68,48,10]`；非目标变化0，透明轮廓不变 |

三项修改的JSON再次独立渲染均与PNG完全一致。场景屋顶修改后，其他组件像素不变，重新拼合与独立整图JSON控制一致；不读取旧组件PNG。所有命令、失败、图片和规格保存在 `evaluation/recipes-20261023/`，摘要见 [recipe-workflows.json](measurements/recipe-workflows.json)。

常用编辑入口明显短于展开点集，但输出规格不缩减：

| 资产 | 可读配方 | 原展开JSON |
|---|---:|---:|
| 图标组 | 35行 / 1,654字节 | 139行 / 3,228字节 |
| 六态按钮 | 49行 / 2,777字节 | 481行 / 9,618字节 |
| 128飞船 | 49行 / 2,535字节 | 33,744行 / 439,756字节 |

另外有一份共享辅助文件2,613字节，处理点集裁切、输出与命令参数；完整运行时仍需随包。上表是源码体积，**不是token节约、绘制能力或实际修改轮次的测量**。简单任务可以只改CLI参数；复杂新形状仍需编辑源码并看图。

## 验收与代价

- 本轮86个源码测试、43张稳定迁移图、77项独立ZIP场景及官方skill-creator格式校验通过。10张外部最终图重渲染及布局保持一致；138个受保护原工具/资源/输入文件哈希不变。
- 原公共接口、JSONv1、端点/合成语义和旧命令保持不变。冻结rc.2任务包继续用于三平台复测；rc.3不替换任务中途的工具。
- 包体从213,762增至222,984字节，增加9,222字节（约4.3%）；文件85→91。Python配方比静态JSON有更多执行能力，只运行可信的配方。
- 代理自查实际查看了前后图、UI原尺寸/深浅底/灰度/标注图和场景预览。图标形状、飞船方向、按钮焦点/选中标记保留，文字区没有覆盖图标和状态标记；颜色变体不宣称更美。
- 未验证真实字体适配、交互和游戏内表现；这些由P3消费端演示解决。跨Pillow精确复现仍以12.3.0为基准，兼容版本的多边形光栅结果可能不同。rc.3当前提交的新版CI状态另行记录，不能拿rc.2成功冒充。

稳定发布及本地已安装Skill维持v1.1.1。本轮不做普遍审美、耗时、token或外部Agent成功率改善宣传。下一步P3：加载这些真实PNG、使用明确字体和真实文字，验证六态、1/2/3倍缩放及一次修改后更新的完整流程；之后才做独立256分块。
