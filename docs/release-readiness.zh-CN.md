# 正式版还差什么

更新：2026-10-25。当前实现已推送 `codex/visual-quality`，本地候选rc.5；正式Release和本地安装仍为1.1.1。本文是发布状态核对与建议，不更改原验收约定，不授权发布、合并或安装。

## 已有证据

rc.5通过103源码测试、43稳定图回归、91独立ZIP场景、官方Skill格式校验、中文/空格路径实际命令及实现提交8组Windows/Ubuntu/Pillow CI。三份P1外部提交均已核验：13组规格PNG精确重建，三张编辑结果区外RGBA变化0。原始资料与旧候选保留。未发现新的核心像素阻断缺陷，不能据此承诺没有未知缺陷。

代码已推送开发分支。尚未完成的是正式版验收及main/tag/Release交付，不是一次网络推送失败。

## 真正未闭合的项目

| 项目 | 已知与未知 | 对发布的意义 |
|---|---|---|
| rc.5最短编辑入口 | `import --cell`源码/整包/协调端实际闭环通过；外部三份用的是rc.2，尚无人从新会话按rc.5指导实际完成 | 优先补一次小范围外部上手，观察是否仍需手抄布局、手造sidecar或因候选命名卡住 |
| 新版是否更省步骤/修正 | 现有任务命令多、候选多，条件不同，没有有效新旧配对；大规格/报告仍可能增加阅读成本，配方与选格的实际模型收益未测 | 不能宣传普遍减少轮次/耗时/token；也是原稳定门槛尚未达成的主要原因 |
| 云挂载原生输出 | 千问硬链接EPERM有记录，便携路径产物精确；挂载仅自报ossfs2，/tmp成功无相应命令/PNG | 应明确要求显式便携模式及其写入可见性限制；不宣称所有云文件系统原生支持，不必要求每种挂载都原生成功 |
| 实际消费端覆盖 | 浏览器真实字体/状态/输入/缩放示例通过；Minecraft目标版本GUI Scale、UV、实际字体/邻接与游戏内效果未验 | 通用PNG/渲染器可声明范围；若宣传Minecraft即插即用，则需目标项目实测 |
| 绘画质量与跨模型创作 | 原生128/256、独立可运行块有作者检查，外部有小改图；缺独立盲评及多模型协作整场景证据 | 不保证审美自动提高、跨块语义自动连续；512不是当前正式版前置条件 |

另有已知约束：PNG导入不能恢复图层；高色数转行段后规格可能很长（有4MiB限制）；跨Pillow版本的部分多边形填充可能不同，精确复现固定12.3.0。它们不应写成“尚未发现的问题”或被103项测试掩盖；发布时写清适用范围。

## 原约定与建议必须分开

原约定尚有效：工程检查全通过，两个代表环境各完成8项新旧配对，无关键退步，至少6项在定位成功率或修改轮次上有具体收益、另一环境无反向退步，另有独立视觉复查。旧指南最低为2×8×2=32次新会话。已收8项探索和3项P1不满足这套设计。

旧测评包固定v1.1.0与rc.1，若继续严格执行，先冻结当前候选和明确的对照版本、任务/预算/顺序，准备对应包；不能拿旧包结果宣称rc.5通过，也不把现有探索记录回填成受控结果。

从实用工具交付角度，建议由用户明确决定是否将稳定版门槛调整为“正确性、兼容性和新用户可用性”，把版本效率/普遍审美声明单独验收。建议的精简补证是两个支持执行的外部新会话，一个Windows、一个Linux：一项命名单格编辑，一项配方→PNG/布局→实际界面使用；只给rc.5包、需求和必要原始资产，不预告解法。保留真实命令、规格、PNG及失败；检查是否完成、是否靠协调端补救、区外变化和方向/状态/内容问题。这支持上手和交付判断，不是受控版本收益证明。

上述精简路线是建议，尚未替代原32会话/至少6项收益的门槛。不得据本文自动发布稳定。

## 验收后剩余的发布收尾

1. 固定正式范围及已知限制，停止继续加功能；确认要执行的验收约定。
2. 验收通过后将版本改为1.2.0，用最终版本源码生成包并执行必要工程/整包/格式检查，记录新摘要。
3. 审阅并合并main，创建对应tag/正式Release，附ZIP、SHA-256、双语说明及有证据的结论。
4. 实际下载公开附件复核摘要，再按既有约定备份并更新本地Skill，检查文件及实际入口。

这些是有限的交付步骤；512、动画、自动铺砖、新旋转语法、更多图库不是本次前置要求。

四主阶段位置：P1工程核验完成、P2/P3完成、P4a原生256完成，P4b512按需求暂缓。当前处于正式版验收/交付边界，未另开第五功能阶段。
