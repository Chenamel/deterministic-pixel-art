# v1.1.1 — reliability fixes from external feedback

- Null mask outlines now equal omission; explicitly transparent outlines retain their replacement semantics.
- Native, grayscale and cell review cards use the selected primary background.
- Wide sources use adaptive sheets; very large views expose labeled native crops and an overview.
- Output groups are staged and reserved before single-file atomic publication, with rollback on ordinary errors.
- Bounds, DSL, missing dependencies and deep JSON have actionable diagnostics.
- Pillow 10.4/11.3/12.1 compatibility and POSIX venv invocation are covered alongside the 12.3 baseline.

Local verification: 42 source tests, all 43 stable migration pixels unchanged,
37 isolated ZIP execution cases and the official skill-creator validator pass.
Windows/Ubuntu CI results must also pass before publishing this release.
PNG bytes across different Pillow/zlib environments are not promised identical.

Details: [feedback report](../audit-feedback.md). These are reliability changes,
not a new claim of general aesthetic improvement. Crash-safe multi-file
transactions, fonts and in-game verification remain outside this patch.

Downloads include the standalone Skill ZIP, per-file manifest and SHA-256 sums.
Keep the existing editable specifications; no artwork redesign is required.
