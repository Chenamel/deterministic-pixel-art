# v1.2.0-rc.1 — text inspection and exact PNG editing

This is a **prerelease**. The latest stable release and local Codex installation
remain **v1.1.1**, which contains the external-feedback reliability fixes.

## New capabilities

- `inspect` / `inspect_image`: bounded pixel geometry, palette, alpha coordinates,
  4/8-neighbor components, symmetry, named cells, exact local grids and comparisons.
- `import` / `image_to_spec`: static 8-bit PNG to editable JSON v1, preserving all
  decoded RGBA pixels, including partial alpha and hidden RGB. No quantization.
- Shared review analysis; versioned content-bound sidecars, `--metadata` reuse and
  optional `--embed-metadata` layout records. Existing JSON v1 and render semantics
  remain compatible.
- Short skill paths for small edits, text-only work and visual review; specialist
  guidance remains optional.

## Verification and measured costs

61 source tests, 43 unchanged stable outputs, eight exact import/inspection tasks,
45 isolated Skill ZIP scenarios, the official skill-creator validator and 15
evaluation-bundle smoke checks pass locally. Windows/Ubuntu CI must pass on the
tagged commit. Across Pillow versions, compare decoded RGBA rather than PNG bytes.

One Windows/Python 3.14.2/Pillow 12.3.0 comparison with v1.1.0 found pure rendering
essentially unchanged. Full render/review medians rose by 15.0/16.7 ms (about 9%);
sample review JSON grew from 1,237 to 6,999 bytes. These are real runtime/context
costs. Agent productivity, correction-round savings, token savings and general
aesthetic improvement remain unproven.

## External evaluation remains pending

The agent bundle contains A/B runtimes, eight fixed local-repair tasks, inputs,
requests and the command recorder. The **separate evaluator bundle** contains
answers, version mapping, verification runtime and an independent visual-review
template. Do not give that bundle to the tested agents.

Use fresh conversations for all eight A/B tasks in both a text-only and a
multimodal environment. Keep each environment's model, prompt and budget fixed;
save real commands, localization, specs, PNGs, transcripts and failure records.
Unknown token usage stays null. See `README.md` inside the agent ZIP.

Engineering checks alone cannot promote this candidate. The agreed gate also
requires complete paired results, no critical semantic/content regression, and
concrete localization or revision-count improvement in at least six task IDs
without opposing regression. There are currently **zero new external runs**;
the attached pending-gate report correctly returns false. Scripted smoke checks
and historical v1.0→v1.1 reports do not satisfy this gate.

Downloads include the Skill ZIP, per-file manifest, both evaluation ZIPs,
capability/performance/pending reports and SHA-256 sums. Keep the evaluator
download with the person coordinating the trials. No font or in-game acceptance
is claimed. MIT licensing is unchanged.
