# v1.2.0 — editable pixels and scoped workflows

Create and edit pixel-art PNG icons, sprites, UI components, named atlases and component scenes from text specifications or short Python recipes. Minecraft styling remains optional.

## Changes since v1.1.1

- Inspect bounded image facts: geometry, palette, alpha, components, symmetry and local symbol grids. Review on explicit backgrounds and reuse named atlas layouts.
- Import static 8-bit PNGs without quantization, including hidden RGB under zero alpha. Import a full image or a verified named atlas cell; edit and replace one cell while retaining the other cells and layout.
- Verify exact RGBA changes against allowed regions or masks. Assemble separately rendered PNG components with declared crops, overlaps and coverage; inspect coordinate-labeled seams.
- Use editable recipes for icons, button states, a native128 sprite, component scenes and a two-owner bridge with global material phase. Guidance routes small edits, text inspection, visual work and consumer checks separately.
- Set `PIXELART_PORTABLE_OUTPUT=1` once per task shell when hard-link publication is unavailable. CLI and recipes inherit it; explicit per-command flags take priority. Existing no-overwrite behavior remains in force.

## Compatibility and setup

Python 3.10+ and Pillow >=10.4,<13 are supported. `requirements.txt` pins Pillow 12.3.0 for reproducibility; the reference environment is Python 3.14.2 / Pillow 12.3.0. Runtime dependencies remain Python and Pillow.

JSON v1 and existing API/command defaults remain compatible. Drawing primitives overwrite RGBA; blits use source-over composition unless an explicit supported alternative is chosen. PNG round trips preserve decoded 8-bit RGBA, not necessarily compressed PNG bytes, layers or original drawing instructions. Animation and unsupported high-bit-depth inputs are rejected.

Extract the ZIP, install its `requirements.txt` in the task's Python environment, then run from the extracted parent directory:

```sh
python deterministic-pixel-art/scripts/pixel_art.py render --spec deterministic-pixel-art/assets/gem-16.json --out output/gem.png --preview output/gem-preview.png
python deterministic-pixel-art/scripts/pixel_art.py inspect --image output/gem.png --grid
```

Keep old Skill backups outside the discovery directory. In portable-output mode, new files may be visible while being written; this does not provide cross-file power-loss transactions.
