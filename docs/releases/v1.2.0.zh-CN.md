# v1.2.0 — 可编辑像素与精确修改工作流

通过文本规格或简短 Python 配方创作、编辑像素 PNG 图标、精灵、UI、命名图集和组件场景。Minecraft 风格继续按需选用。

## 相对 v1.1.1 的变化

- 提供有输出预算的图片事实分析：几何、调色板、Alpha、连通分量、镜像差异和局部符号网格；审阅支持明确背景和命名图集布局复用。
- 无损导入静态8位 PNG，不量化颜色，保留全透明像素里的 RGB；可导入整图或经过布局核验的命名单元，替换一格并保留其他单元及布局。
- 按允许区域或蒙版核对精确 RGBA 变化；组合独立渲染的 PNG 组件，声明裁切、覆盖与重叠，并检查带坐标的接缝。
- 附带图标、按钮状态、原生128精灵、组件场景及共享材质相位的双块桥梁配方；小改、文本分析、视觉审阅和消费端检查各有简短入口。
- 不支持硬链接发布的任务，可在 shell 一次设置 `PIXELART_PORTABLE_OUTPUT=1`，由 CLI 和配方继承；单命令显式选项优先，拒绝覆盖规则保持。

## 兼容性与运行

支持 Python 3.10+、Pillow >=10.4,<13。`requirements.txt` 锁定 Pillow 12.3.0；固定复现环境为 Python 3.14.2 / Pillow 12.3.0。运行依赖仍只有 Python 与 Pillow。

JSON v1 和既有 API、命令默认行为保持兼容。基础绘图覆写 RGBA，blit 默认采用 source-over 合成，其他支持的行为需显式选择。PNG 往返保留解码后的8位 RGBA，不承诺相同压缩字节，也不恢复图层或原始绘制指令；动画及不支持的高位深输入会被拒绝。

解压 ZIP，在任务实际使用的 Python 环境安装包内 `requirements.txt`，然后从解压后的父目录运行：

```sh
python deterministic-pixel-art/scripts/pixel_art.py render --spec deterministic-pixel-art/assets/gem-16.json --out output/gem.png --preview output/gem-preview.png
python deterministic-pixel-art/scripts/pixel_art.py inspect --image output/gem.png --grid
```

旧 Skill 备份放在技能发现目录之外。便携输出的新文件在写入中可能可见；它不提供跨文件掉电事务保证。

## 依据与边界

正式编号后的内容已通过165项源码测试、106项独立包场景、43张稳定图片检查、可复现打包和官方 Skill 格式校验。98文件中97个与已验收开发包字节相同，剩余模块仅修改版本常量；`verification.json`记录精确发布提交、对应 Windows/Ubuntu CI结果和准备包来源。

外部材料覆盖八类任务；LT04 原始方向错误、早期版本缺失，以及 LT08 早期过程不完整均继续保留。这些试用不能证明普遍画质、任务耗时或 token 收益。Minecraft 游戏内集成、任意字体、原生512和多代理协作绘制仍未验证；图片测量和工程检查通过不等于语义或审美验收。
