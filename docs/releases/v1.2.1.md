# v1.2.1 — clearer guidance and Skill icons in the download

This maintenance update packages the wording corrections and Pixel Anchor icons previously reviewed in the repository.

## Changes

- Clarify Chinese and English descriptions of interrupted writes, report-size limits and image checks in the target game or application. Commands and functional requirements are unchanged.
- Include 32×32 and 128×128 Skill icons, with the updated display name, description and icon paths. README headers and fonts remain repository-only.
- Keep rendering, PNG import, scoped edits, atlas replacement, validation, assembly and example behavior unchanged. The only runtime-source change from v1.2.0 is the version constant; JSON v1, Python APIs and example pixels remain compatible.

## Installation and files

Follow the [AI installation guide](https://github.com/Chenamel/deterministic-pixel-art/blob/main/INSTALL.md), download this release's ZIP and check it against `SHA256SUMS.txt` before extraction. Python 3.10+ and Pillow >=10.4,<13 are supported; the packaged `requirements.txt` pins Pillow 12.3.0. Keep update backups outside the folders the agent scans for Skills.

Download attachments are `deterministic-pixel-art-v1.2.1.zip`, `package-manifest.json`, `verification.json` and `SHA256SUMS.txt`. English and Chinese notes are readable on the Release page, without separate Markdown downloads. `verification.json` records the release commit, CI results, package hash and checks.

The original v1.2.0 ZIP and tag remain available and unchanged. Downloading the new package does not update an existing installation. Whether an AI application displays the Skill icons still needs to be checked after that application loads the package.

## Verification scope

Release checks cover package files and hashes, icons and display metadata, execution after extraction, existing commands and examples, and repeatable packaging. Exact results and the checked commit are recorded in `verification.json`.

External trials do not establish general improvements in image quality, task time or token use. LT04's original direction error and LT08's incomplete early history remain recorded. Minecraft game integration, other fonts, artwork drawn directly at 512×512 and drawing by multiple agents still need separate validation.
