# v1.2.1 — 说明更清楚，正式包加入 Skill 图标

这是 v1.2.0 的维护更新，将此前已在仓库完成的说明修正和 Pixel Anchor 图标纳入正式下载包。

## 本次变化

- 改写难懂的中英文说明，直接解释文件写入中断、报告长度限制，以及在实际游戏或应用中检查图片的方法；原有命令和功能要求不变。
- 包内加入 32×32、128×128 两张 Skill 图标，并更新展示名称、简介和图标路径。README 标题图和字体仍只放在仓库，不进入 Skill ZIP。
- 渲染器、PNG 导入、局部修改、图集替换、校验、组件拼接和示例脚本的行为均未改变。运行时代码相对 v1.2.0 只修改版本号；JSON v1、Python API 和示例图片保持兼容。

## 安装和文件

按 [AI 安装指南](https://github.com/Chenamel/deterministic-pixel-art/blob/main/INSTALL.md) 下载本版 ZIP，核对 `SHA256SUMS.txt` 后再解压。运行需要 Python 3.10+ 和 Pillow >=10.4,<13；包内 `requirements.txt` 指定 Pillow 12.3.0。更新时请保留旧版备份，并将备份放到 AI 不会扫描加载 Skill 的目录。

下载附件为 `deterministic-pixel-art-v1.2.1.zip`、`package-manifest.json`、`verification.json` 和 `SHA256SUMS.txt`。中英文说明在 Release 页面直接阅读，不另附需要下载的 Markdown 文件。`verification.json` 记录本次发布对应的提交、CI、包摘要和检查结果。

v1.2.0 的原 ZIP 和 tag 保留不变。下载新包不会自动更新已有安装；Skill 图标能否在某个 AI 应用中显示，还需由该应用加载后确认。

## 验证范围

发布检查核对包内文件和摘要、图标与展示配置、独立解压运行、已有命令和示例，以及重复打包结果。实际结果和精确提交以 `verification.json` 为准。

外部试用不能证明工具能普遍改善画质、缩短任务时间或节省 token。原有 LT04 方向错误和 LT08 早期过程记录不全的限制继续保留。Minecraft 游戏内效果、其他字体、512×512 直接绘制和多个 AI 协作绘图仍需分别验证。
