# v1.2.2 — optional scene guidance and distribution packages

2026-11-02. This maintenance release packages the optional guides and distribution tools already reviewed in the repository. Downloading it does not update an existing installation.

## Changes

- Include the merged action-icon card and optional scene-space and scene-revision guides. They cover viewing direction, connected forms, object placement, surface-bounded fills, readable patterns and related changes. Read the relevant section when useful; user references take priority.
- Include the reviewed full-size Pixel Anchor logo kit as a separate download: six appearances at 32/64/128/256/512px, editable specifications, previews, license and checksums. The 256/512px badges have enhanced detail; the smaller badges and transparent marks remain simple. The Skill keeps its existing 32/128px icons.
- Include the merged local-link checking fix in the package checks. Add a separate [SkillHub packaging tool](../skillhub-distribution.zh-CN.md) that adds platform metadata to the complete Skill without changing its generic copy.

## Behavior and dependencies

The only runtime-source change from v1.2.1 is the version constant. Rendering, PNG import, named-cell replacement, exact RGBA verification, assembly, JSON v1, Python APIs, recipes and example pixels remain unchanged.

Python 3.10+ and Pillow >=10.4,<13 remain the declared range; requirements.txt pins Pillow 12.3.0 for reproduction. Windows compatibility sampling reached Python 3.15.2 with that baseline. Pillow 13 passed a relaxed-guard experiment, but remains outside the supported range. The NPX installer requires its own Node runtime, installs files from the repository branch and still requires Python/Pillow setup; use the complete Skill subdirectory in [INSTALL.md](../../INSTALL.md).

## Packages

The GitHub attachments are `deterministic-pixel-art-v1.2.2.zip`, `deterministic-pixel-art-logos.zip`, `package-manifest.json`, `verification.json` and one `SHA256SUMS.txt` covering the other four files. English and Chinese notes are readable on the Release page. The [SkillHub tool](../skillhub-distribution.zh-CN.md) creates a separate platform upload package with root SKILL.md, the same runtime version and a recorded source commit; platform login, slug ownership and review are separate from local packaging. This GitHub release does not upload to SkillHub.

The frozen Skill ZIP passed 106 isolated execution checks; the platform ZIP passed the same 106 checks. All 30 editable logo specifications rerendered to identical RGBA. The official SkillHub collector matched all 104 platform files; its dry-run checked metadata only. [Exact-candidate CI](https://github.com/Chenamel/deterministic-pixel-art/actions/runs/41326354539) passed all eight Windows/Ubuntu jobs, with 178 source tests in each compatibility job. The attached `verification.json` records the final release commit, its main CI and the unchanged package hashes. These checks are mechanical acceptance by the coordinating model, without a new independent model review or creative trial.

## Limits

The guides and packaging checks do not establish general improvements in artwork quality, autonomous correction, time or token use. Existing external trial failures and evidence limits remain recorded. Native512 creative validation and other unselected features remain outside this maintenance release.
