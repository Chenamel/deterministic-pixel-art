# v1.2.2 — optional scene guidance and distribution packages

This is a local maintenance candidate. It has not been published; the stable download remains v1.2.1. Candidate preparation does not update an existing installation.

## Changes

- Include the merged action-icon card and optional scene-space and scene-revision guides. They cover viewing direction, connected forms, object placement, surface-bounded fills, readable patterns and related changes. Read the relevant section when useful; user references take priority.
- Include the reviewed full-size Pixel Anchor logo kit as a separate download: six appearances at 32/64/128/256/512px, editable specifications, previews, license and checksums. The 256/512px badges have enhanced detail; the smaller badges and transparent marks remain simple. The Skill keeps its existing 32/128px icons.
- Include the merged local-link checking fix in the package checks. Add a separate [SkillHub packaging tool](../skillhub-distribution.zh-CN.md) that adds platform metadata to the complete Skill without changing its generic copy.

## Behavior and dependencies

The only runtime-source change from v1.2.1 is the version constant. Rendering, PNG import, named-cell replacement, exact RGBA verification, assembly, JSON v1, Python APIs, recipes and example pixels remain unchanged.

Python 3.10+ and Pillow >=10.4,<13 remain the declared range; requirements.txt pins Pillow 12.3.0 for reproduction. Windows compatibility sampling reached Python 3.15.2 with that baseline. Pillow 13 passed a relaxed-guard experiment, but is not added to this candidate's support declaration. The NPX installer requires its own Node runtime, installs files from the repository branch and still requires Python/Pillow setup; use the complete Skill subdirectory in [INSTALL.md](../../INSTALL.md).

## Packages

The planned GitHub attachments are the versioned Skill ZIP, separate logo ZIP, package-manifest.json, verification.json and one SHA256SUMS.txt covering that set. English and Chinese notes stay readable on the Release page. The SkillHub ZIP is a separate platform upload package with root SKILL.md, the same runtime version and a recorded source commit; platform login, slug ownership and review are separate from local packaging.

Candidate preparation checks packaging prerequisites, file contents and hashes. Full candidate acceptance and CI on its exact commit belong to the next step. A prior main CI result is not this candidate's CI. See the candidate delivery record for the actual checks and outstanding gates.

## Limits

The guides and packaging checks do not establish general improvements in artwork quality, autonomous correction, time or token use. Existing external trial failures and evidence limits remain recorded. No new creative/model trial is required for this maintenance candidate; native512 creative validation and other unselected features remain outside it.
