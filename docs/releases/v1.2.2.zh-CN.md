# v1.2.2 — 可选场景指南与分发包

2026-11-02。本次维护版交付仓库中已审阅的可选指南与分发工具。下载版本包不会自动更新已有安装。

## 变化

- 纳入已合并的动作图标卡、场景空间与场景修订选读指南，涉及观察方向、相连体块、对象位置、限定在表面内的填色、可读纹理及相关部件的同步修改。需要时读相关段落，用户参考优先。
- 将已审阅的全尺寸 Pixel Anchor Logo 素材作为独立下载：六种外观、32/64/128/256/512px，包含可编辑规格、预览、许可与摘要。256/512px 徽章采用增强细节，较小徽章与透明标记保持简洁；Skill 仍使用现有 32/128px 图标。
- 纳入已合并的包内链接检查修复。增加独立的 [SkillHub 打包工具](../skillhub-distribution.zh-CN.md)，从完整 Skill 生成平台元数据，不改通用副本。

## 行为与依赖

相对 v1.2.1，运行时源码仅改变版本常量。绘图、PNG 导入、命名单格替换、RGBA 精确核对、拼接、JSON v1、Python API、配方和示例像素均保持。

声明范围仍为 Python 3.10+、Pillow >=10.4,<13；requirements.txt 固定 Pillow 12.3.0 用于复现。Windows 抽样已验证 Python 3.15.2 配合该基准；Pillow 13 在放宽检查的实验副本中通过，仍在支持范围之外。NPX 安装器需要自己的 Node 环境，从仓库分支复制文件，之后仍要准备 Python/Pillow；使用 [INSTALL.md](../../INSTALL.md) 中的完整 Skill 子目录入口。

## 包文件

GitHub 附件为 `deterministic-pixel-art-v1.2.2.zip`、`deterministic-pixel-art-logos.zip`、`package-manifest.json`、`verification.json`，以及覆盖其余四份文件的一份 `SHA256SUMS.txt`。双语说明在 Release 页面直接阅读。[SkillHub 工具](../skillhub-distribution.zh-CN.md) 另行生成平台上传包，根目录是 SKILL.md，运行时版号相同并记录源提交；账号登录、slug 所有权与平台审核另行完成。本次 GitHub 发布不包含 SkillHub 上架。

固定 Skill ZIP 的 106 项隔离执行检查通过，平台 ZIP 的同组 106 项检查也通过；30 份 Logo 可编辑规格重绘后的 RGBA 一致。官方 SkillHub 文件收集器核对了全部 104 份平台文件，其 dry-run 仅检查元数据。[精确候选 CI](https://github.com/Chenamel/deterministic-pixel-art/actions/runs/41326354539) 的 Windows/Ubuntu 共八项任务全部通过，各兼容任务运行 178 项源码测试。附件 `verification.json` 记录最终发布提交、对应 main CI 与保持不变的包摘要。这些是主协调模型完成的机械验收，本轮没有新增独立模型评审或创作试验。

## 限制

指南和打包检查不证明普遍画质、自主纠错、时间或 token 收益。原外部试验失败和证据局限继续保留。原生 512 创作验证及其他未选功能仍在本维护版范围之外。
