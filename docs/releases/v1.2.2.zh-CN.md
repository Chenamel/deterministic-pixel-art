# v1.2.2 — 可选场景指南与分发包

这是本地维护候选，尚未发布；稳定下载仍为 v1.2.1。准备候选不会更新已有安装。

## 变化

- 纳入已合并的动作图标卡、场景空间与场景修订选读指南，涉及观察方向、相连体块、对象位置、限定在表面内的填色、可读纹理及相关部件的同步修改。需要时读相关段落，用户参考优先。
- 将已审阅的全尺寸 Pixel Anchor Logo 素材作为独立下载：六种外观、32/64/128/256/512px，包含可编辑规格、预览、许可与摘要。256/512px 徽章采用增强细节，较小徽章与透明标记保持简洁；Skill 仍使用现有 32/128px 图标。
- 纳入已合并的包内链接检查修复。增加独立的 [SkillHub 打包工具](../skillhub-distribution.zh-CN.md)，从完整 Skill 生成平台元数据，不改通用副本。

## 行为与依赖

相对 v1.2.1，运行时源码仅改变版本常量。绘图、PNG 导入、命名单格替换、RGBA 精确核对、拼接、JSON v1、Python API、配方和示例像素均保持。

声明范围仍为 Python 3.10+、Pillow >=10.4,<13；requirements.txt 固定 Pillow 12.3.0 用于复现。Windows 抽样已验证 Python 3.15.2 配合该基准；Pillow 13 在放宽检查的实验副本中通过，但本候选没有将其加入支持范围。NPX 安装器需要自己的 Node 环境，从仓库分支复制文件，之后仍要准备 Python/Pillow；使用 [INSTALL.md](../../INSTALL.md) 中的完整 Skill 子目录入口。

## 包文件

计划中的 GitHub 附件为版本 Skill ZIP、独立 Logo ZIP、package-manifest.json、verification.json，以及覆盖这组文件的一份 SHA256SUMS.txt。双语说明保留在 Release 页面上。SkillHub ZIP 单独用于平台上传，根目录是 SKILL.md，运行时版号相同并记录源提交；账号登录、slug 所有权与平台审核另行完成。

候选准备检查打包前置条件、文件内容和摘要。完整候选验收与精确提交 CI 属于下一小步；先前 main 的 CI 不能代替本候选 CI。实际完成检查与待办以候选交付记录为准。

## 限制

指南和打包检查不证明普遍画质、自主纠错、时间或 token 收益。原外部试验失败和证据局限继续保留。本维护候选不需要新增创作/模型试验；原生 512 创作验证及其他未选功能仍在本轮范围之外。
