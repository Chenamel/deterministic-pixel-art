# v1.3.0 — Scoped recoloring, atlas pages, tile previews, and PNG frame export

[简体中文](v1.3.0.zh-CN.md)

2026-11-15. Compared with v1.2.2, v1.3.0 adds scoped RGBA color replacement, paged native-size atlas review, tile seam and scene previews, and packaging for existing PNG animation frames. Install the standalone Skill ZIP following [INSTALL.md](../../INSTALL.md); downloading an archive does not update an existing installation.

## Changes since v1.2.2

- **Scoped recoloring:** `recolor` applies exact RGBA mappings simultaneously within explicit rectangles or a mask while leaving identical colors outside untouched. The existing `verify` command checks full RGBA differences, including RGB values under zero-alpha pixels, and verifies edit bounds.
- **Paged atlas review:** `recipes/review_atlas.py` splits large named atlases into bounded pages at 1:1 native pixel size on dark and light backgrounds and records each page's cells in `index.json`. Generating the index does not establish that an agent viewed every page.
- **Tile and scene previews:** `recipes/tile_preview.py` repeats a single tile along `x`, `y`, or `xy` to inspect seams; `recipes/tile_scene.py` places explicitly named atlas tiles into a layout and outputs the scene, seam views, and a relocatable `assemble` project without inferring terrain transitions, perspective, or pixel repairs.
- **PNG animation export:** `recipes/animation_export.py` organizes equal-size single-frame PNGs, action ranges, and millisecond timings into a relocatable directory while keeping original PNG bytes. Optional GIFs provide playback previews; the script does not draw frames or export sprite sheets/APNGs.
- **DSH bundle and demo:** The repository adds source for the optional third-party [DSH bundle](../../integrations/dsh/README.md) (`0.1.2`) and updates the [editable travel-kit demo](../../demos/travel-kit/README.md) (in the repository checkout, not the standalone Skill ZIP).

## Reliability fixes and input boundaries

- **Metadata and review focus:** Strict named-atlas operations verify that layout metadata matches the image pixels. When `review` sheets exceed size budgets, crops prioritize visible changes first and declared regions second.
- **Embedded layout limit:** Reading and writing embedded PNG layout metadata share a 256 KiB limit on actual serialized UTF-8 bytes (including escaped Unicode), rejecting oversize records before writing outputs. Standalone layout JSON files are not subject to this embedding limit.
- **Backup retention and clean builds:** If output replacement and rollback both fail, old-file backups are retained and their paths are reported (without promising atomic multi-file recovery across crashes or power loss). Release packaging reads from designated source and guide directories so leftover generated files are excluded.
- **Exact-edit inputs and runtime:** Exact editing (`recolor` and `verify`) requires single-frame PNGs with channel depth at most 8 bits; multi-frame PNGs/APNGs and non-PNG inputs are rejected on the CLI before writing outputs, while Python APIs check the passed image mode and frame count. Existing commands and JSON v1 remain available on **Python 3.10+** and **Pillow >=10.4,<13** (`requirements.txt` pins Pillow `12.3.0`). PNG import does not reconstruct original layers.
