# v1.3.0 — 局部改色、图集分页、地块预览与 PNG 动画帧导出

[English](v1.3.0.md)

2026-11-15。相对 v1.2.2，v1.3.0 新增限定范围的 RGBA 改色、大型命名图集原尺寸分页预览、瓦片平铺与命名场景预览，以及已有 PNG 动画帧的打包导出。请按 [INSTALL.md](../../INSTALL.md) 安装独立 Skill ZIP；下载压缩包不会自动更新已有安装。

## 相对 v1.2.2 的变化

- **局部改色：** `recolor` 在显式矩形或蒙版内同时替换精确 RGBA 颜色，范围外的同色像素保持不变。配合既有的 `verify` 命令可检查完整 RGBA 差异（含全透明像素下的 RGB）并核对改动是否越界。
- **图集分页查看：** `recipes/review_atlas.py` 按 1:1 原生像素尺寸将大型命名图集拆分为尺寸受控的预览页，在深浅背景上展示并生成 `index.json` 记录每页单元。生成覆盖清单不代表模型已实际查看所有页面。
- **地块与场景预览：** `recipes/tile_preview.py` 沿指定方向重复平铺单块瓦片以检查接缝；`recipes/tile_scene.py` 按明确名称排布图集地块，输出场景图、接缝图和可搬移的 `assemble` 工程，不自动推断地形过渡、透视关系或修补画面。
- **PNG 动画帧导出：** `recipes/animation_export.py` 将已有的等尺寸单帧 PNG、动作区间和毫秒时长整理为可搬移目录并保留原始 PNG 字节。可选 GIF 仅作播放预览；工具不负责画帧，也不导出精灵表或 APNG。
- **DSH 插件与仓库示范：** 仓库新增可选第三方 [DSH 插件包](../../integrations/dsh/README.zh-CN.md)（`0.1.2`）源码，并更新了首页的[可编辑旅行用品示范](../../demos/travel-kit/README.md)（位于仓库源码中，不含在独立 Skill ZIP 内）。

## 可靠性修正与输入边界

- **布局绑定与裁剪优先级：** 命名图集的严格操作会核对布局记录与图像像素是否一致；当 `review` 预览页超出画幅预算时，局部裁剪优先覆盖变化区域，其次覆盖声明区域。
- **内嵌布局容量限制：** 写入与读取 PNG 内嵌布局记录共用 256 KiB 的实际序列化字节上限（含转义 Unicode 字节），超限时在写出前拒绝；独立外部布局 JSON 不受此内嵌上限约束。
- **旧文件备份与打包输入：** 覆盖输出且回滚失败时，保留旧文件备份并报告路径（不承诺断电或崩溃下的多文件原子恢复）。发行打包仅从指定的源码与指南目录收集权威输入，避免混入残留生成文件。
- **精确编辑输入与运行环境：** 精确编辑（`recolor` 与 `verify`）要求单帧、通道位深不超过 8 位的 PNG；CLI 在写出前拒绝多帧 PNG/APNG 与非 PNG 输入，Python API 则检查传入图像的已解码模式与帧数。既有绘图命令与 JSON v1 继续支持 **Python 3.10+**、**Pillow >=10.4,<13**（`requirements.txt` 固定 Pillow `12.3.0`）；PNG 导入不会还原原始图层。
