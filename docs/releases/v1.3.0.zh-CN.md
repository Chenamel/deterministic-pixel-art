# v1.3.0 — 限定范围编辑与可搬移素材交付

2026-11-15。Python 工具与指南请安装完整 Skill ZIP；DSH 用户安装独立的 `dsh-skill-deterministic-pixel-art@0.1.2` bundle。下载文件不会自动更新已有安装。

## 编辑与查看

- 用 `recolor` 在明确的矩形或蒙版内替换精确 RGBA 颜色。颜色映射同时作用于原始像素，允许区域之外的同色像素保持原样。`verify` 检查完整 RGBA 差异，包括透明像素下面的 RGB。
- 用 `review_atlas.py` 按原生尺寸分页查看大型命名图集。覆盖记录说明每页包含哪些单元，不代表模型实际看过了每张图。
- 重建输出时保留源文件。打包在普通替换故障中保留旧的生成输出；布局记录把名称和区域绑定到相应图像的像素。

## 配方与交付

- 用 `tile_preview.py` 和 `tile_scene.py` 预览重复瓦片及按明确名称摆放的地块场景。这些配方展示接缝与位置，不推断地形规则或自动修图。
- 用 `animation_export.py` 导出已有的等尺寸 PNG 帧，明确动作区间和毫秒时长。交付保留原始 PNG 字节及可搬移清单；可选 GIF 采用明确的透明度或背景处理，只作预览，不替代原始帧。
- [DSH bundle](../../integrations/dsh/README.zh-CN.md) 支持配套的 DSH core 与 Skill 0.2.2-rc.1 至 rc.3，要求 Node >=24.9.0、Cordis ~4.1.0。桌面和命令行配置分别安装。

## 输入边界

`recolor` 和 `verify` 要求静态、通道位深不超过 8 位的 PNG。CLI 在写出结果前拒绝非 PNG、高位深 PNG 和 APNG，避免静默转换或只比较首帧。Python API 检查传入图片的已解码模式和帧数；调用者事先丢弃的信息无法恢复。

内嵌布局 JSON 的实际序列化内容上限为 256 KiB，转义后的 Unicode 字节也计入容量。记录超限时在写出前拒绝。大型独立布局 JSON 不受这一内嵌上限限制；需要重新内嵌布局的工作流仍须满足容量要求。

继续支持 Python 3.10+、Pillow >=10.4,<13；`requirements.txt` 固定 Pillow 12.3.0，便于复现。JSON v1 和已有绘图 API 继续可用；PNG 导入不会重建原始图层或索引色工程。

## 安装包

GitHub 发行提供带版本号的 Skill ZIP、独立全尺寸 Logo ZIP、`package-manifest.json`、`verification.json` 和 `SHA256SUMS.txt`。验证记录列明来源提交、对应 CI 与产物摘要。[SkillHub 打包](../skillhub-distribution.zh-CN.md)从同一份 Skill 生成平台上传包；平台账号权限和审核独立于本地验证。

这些改动不证明普遍画质、模型纠错速度或 token 用量有所提升。动画导出不负责画帧，场景预览也不是游戏引擎或自动透视编辑器。
