# v1.4.0 — Asset delivery workflows, defect checks, and DSH 0.1.5

[简体中文](v1.4.0.zh-CN.md)

2026-11-25. Compared with [v1.3.0](v1.3.0.md), v1.4.0 focuses on one-step asset delivery bundles, faster onboarding for AI agents, automatic detection of detached pixels/fragments, and wider DSH compatibility. See [CHANGELOG.md](../../CHANGELOG.md) and [INSTALL.md](../../INSTALL.md).

## What's new since v1.3.0

- **One-step asset bundle (`recipes/asset_toolkit.py`):** Package an asset together with its editable source (`grid` or `draw` JSON, existing PNG, multi-state grid, named atlas, or layered assembly project), 1× native preview, enlarged nearest-neighbor preview, `REBUILD.md`, and `result.zip`, and verify pixel-identical ZIP reconstruction with `rebuild`.
- **Faster agent workflows:** `SKILL.md` now includes ready-to-copy `render`, `deliver`, and `rebuild` commands, and `--mode grid` explicitly documents support for both `kind: grid` and `kind: draw` sources so agents skip extra source-code exploration.
- **Built-in defect checks:** `render` prints inline 8-connected component counts/sizes/bounding boxes, 4-connected isolated pixels, and dark `2×2` advisory hints; `review` checks disconnected regions in single sprites and named atlas cells.
- **Check & packaging hygiene:** Added `tools/check.py --isolated` for clean-directory verification and normalized LF line endings across 19 workflow example JSON files for reproducible builds.
- **DSH `0.1.5`:** Removed the earlier `0.2.2-rc.3` core upper bound via `engines.dsh: "*"` and wildcard peer ranges, tested across DSH `0.2.2-rc.1`–`rc.5` and `0.2.3-alpha.1` (requires Node `>=24.9.0`, Python `3.10+`, Pillow `>=10.4,<13`).
