# v1.4.0 — 单件打包交付、防断裂检查与 DSH 0.1.5

[English](v1.4.0.md)

2026-11-25。相比 [v1.3.0](v1.3.0.zh-CN.md)，v1.4.0 重点补齐了单件素材一站打包、给 AI 直接抄用的出图/交付命令、悬空碎点与断块自动检查，以及新版 DSH 兼容支持。详情见 [CHANGELOG.md](../../CHANGELOG.md) 与 [INSTALL.md](../../INSTALL.md)。

## 相对 v1.3.0 的主要更新

- **单件素材一站交付（`recipes/asset_toolkit.py`）：** 支持将作品连同可编辑源文件（`grid` 或 `draw` JSON、已有 PNG、多状态素材、命名图集或分层项目）、1× 原尺寸图、最近邻放大预览与 `REBUILD.md` 打进 `result.zip`，并通过 `rebuild` 验证逐像素一致重建。
- **减少 AI 摸索耗时：** `SKILL.md` 新增可直接复制的 `render`、`deliver`、`rebuild` 命令，并在文档与 `--help` 中写明 `--mode grid` 同时支持 `grid` 与 `draw` 源，减少开局先翻源码的往返。
- **自动防呆检查：** `render` 输出直接附带 8-连通分量数量/大小/包围盒、4-邻域孤立像素和暗色 `2×2` 提示；`review` 也对单图和命名图集格补充了断块告警。
- **检查与打包一致性：** 新增 `tools/check.py --isolated` 支持独立隔离目录校验，并统一 19 份工作流示例 JSON 的 LF 行尾以保证重复打包字节一致。
- **DSH `0.1.5`：** 通过 `engines.dsh: "*"` 和通配 peer 范围放开旧版 `0.2.2-rc.3` 内核上限，覆盖 DSH `0.2.2-rc.1`–`rc.5` 与 `0.2.3-alpha.1`（需要 Node `>=24.9.0`、Python `3.10+`、Pillow `>=10.4,<13`）。
