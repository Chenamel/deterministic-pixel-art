# v1.4.1 — Scoped `draw` patches, expanded `Canvas` helpers, bytecode-free CLIs, and DSH 0.1.6

[简体中文](v1.4.1.zh-CN.md)

2026-11-29. Compared with [v1.4.0](v1.4.0.md), v1.4.1 focuses on safer iterative `draw` edits, richer deterministic `Canvas` helpers, clean zero-`__pycache__` CLI runs, and updated DSH packaging. See [CHANGELOG.md](../../CHANGELOG.md) and [INSTALL.md](../../INSTALL.md).

## What's new since v1.4.0

- **Scoped `draw` operation patching (`patch-draw`):** Edit or replace operations inside `asset_toolkit.json` by label, index, or tag using `asset_toolkit.py patch-draw` or `pixelart.toolkit.patch_draw` without rewriting the full spec, plus top-level Python helper re-exports on `pixel_art`.
- **Expanded `Canvas` helpers & starter template:** Adds deterministic `set`, `fill_ellipse`, `mirror_horizontal`, `flip_vertical`, and `to_spec` methods on `Canvas` alongside copyable `SKILL.md` quick-reference snippets and a starter template.
- **Bytecode-free Skill CLIs:** Running `pixel_art.py` or `asset_toolkit.py` directly disables Python bytecode emission (`sys.dont_write_bytecode = True`), and `SKILL.md` standardizes quick-start helper commands on `python -B` to avoid `__pycache__` clutter in target repositories.
- **Test & check hygiene:** Reused completed Minecraft and sprite trial fixtures in tests and updated `tools/self_check.py` to avoid false-positive broken reports on archival historical paths.
- **DSH `0.1.6`:** Bundles Skill `v1.4.1` with the same `engines.dsh: "*"` compatibility across DSH `0.2.2-rc.1`–`rc.5` and `0.2.3-alpha.1` (requires Node `>=24.9.0`, Python `3.10+`, Pillow `>=10.4,<13`).
