# v1.4.1 — 局部 `draw` 补丁、扩展 `Canvas` 方法、零 `__pycache__` 运行与 DSH 0.1.6

[English](v1.4.1.md)

2026-11-29。相比 [v1.4.0](v1.4.0.zh-CN.md)，v1.4.1 重点增强 `draw` 模式的局部迭代修改能力、补全 `Canvas` 绘图/变换方法、消除 Skill 运行产生的 `__pycache__` 污染，并同步更新 DSH 插件包。详情见 [CHANGELOG.md](../../CHANGELOG.md) 与 [INSTALL.md](../../INSTALL.md)。

## 相对 v1.4.0 的主要更新

- **局部绘制指令补丁（`patch-draw`）：** 新增 `asset_toolkit.py patch-draw` 与 `pixelart.toolkit.patch_draw`，支持按 label、索引或 tag 精准修改/替换 `asset_toolkit.json` 中的绘制操作而无需重写整份定义；同时完善 `pixel_art` 顶层常用 Python helper 重导出。
- **更多 `Canvas` 方法与起步模板：** `Canvas` 新增确定性的 `set`、`fill_ellipse`、`mirror_horizontal`、`flip_vertical` 与 `to_spec` 方法；`SKILL.md` 同步补充可直接复制的速查代码与 `Canvas` 起步模板。
- **零 `__pycache__` 污染的 Skill CLI 运行：** 直接调用 `pixel_art.py` 与 `asset_toolkit.py` 时默认禁止写入字节码缓存（`sys.dont_write_bytecode = True`），`SKILL.md` 速查命令统一采用 `python -B`，避免污染用户仓库或 `git status`。
- **测试与自检改进：** 复用已完成的 Minecraft 与精灵评测夹具测试，并修正 `tools/self_check.py` 对历史归档路径的误报。
- **DSH `0.1.6`：** 打包内置 Skill `v1.4.1`，延续通过 `engines.dsh: "*"` 对 DSH `0.2.2-rc.1`–`rc.5` 与 `0.2.3-alpha.1` 的适配支持（需要 Node `>=24.9.0`、Python `3.10+`、Pillow `>=10.4,<13`）。
