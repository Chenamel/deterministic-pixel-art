## 工程依据

准备的 v1.2.0 内容通过165项源码测试、106项独立整包场景、43张稳定图比较、可复现打包和官方 Skill 格式校验。对应准备提交通过8组 Windows/Ubuntu CI，包含 Pillow 10.4、11.3、12.1、12.3。这些数量描述当时准备的内容，不能自动证明之后每个提交均通过。

参见[中文版本说明](releases/v1.2.0.zh-CN.md)、[CI记录](https://github.com/Chenamel/deterministic-pixel-art/actions)和[详细准备记录](releases/v1.2.0-preparation.zh-CN.md)。包清单通过摘要绑定分发文件。PNG兼容比较解码 RGBA，不要求压缩字节一致。固定复现环境为 Python 3.14.2 / Pillow 12.3.0，支持版本之间多边形填充可能不同。

## 外部使用

外部任务材料覆盖图标、精灵、材质变体、通用 UI、消费端文字布局、环境恢复、Minecraft 风格面板和256像素分块。不同 Agent 与环境完成不同任务；它们不是受控模型排名或新旧版本比较。

LT04原提交左右方向相反且缺早期修订，协调端修复不算模型自主纠正。LT08最终像素与观察到的工作流已核验，但最早修订和声称的失败没有完整保留。限制继续记在 [LT04记录](lt04-results-20261029.zh-CN.md)和 [LT08记录](lt08-results-20261030.zh-CN.md)。

## 视觉与消费端限制

自动分析提供几何、调色板、透明度、连通分量和差异，不能证明物体含义、美观或交互语义正确。视觉提示用于引导检查，不是通用画风规则；仍需检查原尺寸和目标背景。

普遍审美提升、token节省和任务提速尚未证明。Minecraft游戏内集成、任意字体、多代理分块创作与原生512验收未验证或属于独立工作。真实字体/浏览器演示和离线接缝检查，只覆盖实际执行的条件。
