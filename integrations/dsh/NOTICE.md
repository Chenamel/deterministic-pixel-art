# Sources and licenses

This third-party bundle is part of Chenamel/deterministic-pixel-art, under MIT
(see LICENSE). It is not an official DeepSeek product.

The `skills/deterministic-pixel-art/` files are generated byte for byte from this
repository's authoritative Skill, Python source, recipes and examples by
`tools/package_dsh.py`, using the same source mapping as `tools/package_skill.py`.
`skill-manifest.json` records their SHA-256 hashes. No second drawing engine is
maintained here.

DSH and Cordis are MIT-licensed peer dependencies from
deepseek-ai/deepseek-harness. They are imported from the host, not included in this
archive. Python and Pillow are separate runtime prerequisites and are not included.
The package has no installation scripts.
